# Evaluation workspaces

Evaluation files are separated by contributor. The main project overview and
final submission entry points are in [the repository README](../README.md).

| Workspace | Contents |
| --- | --- |
| [Yuyao Ding](yuyao_ding/README.md) | Main Part 1 and Part 3 specifications, protocols, recorded results and human reviews; Yuyao's Part 2 partner baseline |
| [Pratiksha Kaushik — Part 3](pratiksha_p3/) | Scenarios, results, judgments, architecture and system card for Pratiksha's independent Part 3 build |

Pratiksha's formal Part 2 experiment is documented in
[her Part 2 README](../notebooks/Pratiksha_Kaushik/p2/README.md), with artifact
locations listed there. Moving Yuyao's evaluation files does not move or replace
those experiments.

The directory split changes paths only. Frozen test content, original JSON/CSV
results and supplied human labels retain their bytes. See Yuyao's
[relocation manifest](yuyao_ding/relocation_manifest.json) for the old/new mapping.
Historical paths and source hashes inside original records refer to the original
execution; they are not rewritten as if new GPU experiments had been performed.
