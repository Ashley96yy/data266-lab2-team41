# Part 3 request traces

The completed Colab T4 run has 40 evaluated request traces (15 with critique,
15 without critique, and 10 red-team) plus one separate diagnostic trace. The
complete raw archive remains private to the team. Raw traces can include input
paths, request text, model outputs, and details derived from private images, so
they have not been copied into this repository.

This directory currently contains no published request traces. A reviewed
export that preserves each agent's input, output, and elapsed time while
protecting private inputs is still needed before the final submission. The
measured run summary is in [the T4 results report](../eval/PART3_T4_MEASURED_RESULTS.md).
